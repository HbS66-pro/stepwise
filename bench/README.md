# bench — 测量台

跑 6 个配置 × 5 个固定任务，出"同任务净额"对照表。结论只有在**同一套口径**下才可比，所以这里把口径和坑先写清。

## 用法

```bash
cp config.example.json config.json    # 填 dshBin / credentials
node setup.mjs                        # 建 6 个隔离 DSH_HOME（每个配置一个）
node run.mjs --configs c0,c2 --tasks t1,t2 --runs 3
node report.mjs                       # 出表：逐格中位数 + 相对 c0 的净变化 + 空跑明细
```

- 配置在 `configs.json`，任务在 `tasks.json`，规则文本在 `policies/`，精简模式的 headless 等价物在 `patches/lean.yml`。
- 结果逐次落盘到 `results/<cfg>-<task>-r<i>.json`（gitignore），原始会话日志在 `_homes/<cfg>/sessions/`。

## 口径（改 `report.mjs` 前先读）

1. **r0 是预热**，冷缓存，不进统计。
2. **成功判定**：`code === 0`，且 `doc` / `long` 类任务必须 `bytes > 0 || files > 0`。**落盘 0 字节记失败**，单列"空跑"，不进中位数。`chat` / `analyze` 不要求落盘。
   > 旧版只看 `code === 0`，会把"进程正常退出但什么都没写"算成成功，把该格中位数往下拉，看起来像省了钱。
3. **报 `costSteady`**（输入全按缓存命中价）的中位数，不报 `cost`：`cost` 含冷缓存首跑，跨配置不可比。
4. 只报中位数和范围，不报均值。

## 三个坑（已在实现里处理）

1. `cwd` 会进系统提示，换目录会让前缀缓存整段失效 → 每个 (配置, 任务) 固定目录。
2. 冷缓存和稳态缓存单价差 50 倍 → 同时记 `cost` 和 `costSteady`。
3. 预热必须按 (配置, 任务) 各做一次，否则第一次跑必然冷。

## 数据来源要标批次

结果文件会按批次攒，同名文件可能是不同次运行。**同一 (任务, 配置, 轮次) 出现两份时，先用白天主批次**；深夜补跑批次只用来填主批次没有的格，引用时必须标出来。`_homes/` 里还留着旧会话日志，可用于逐条复核。

## 已知缺口

- 25 格里每格只有 1–4 次样本，长任务一格只有 2 次。**没有一格达到 5 次**，长尾明显。
- `c3`（低推理档）只跑了 t1–t3；`c1` 的 t4/t5、`c5` 的 t3/t5 来自补跑批次。
- 200 步以上的长会话未覆盖。

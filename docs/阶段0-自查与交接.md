## 3. 自查：误差与未验证

**已核对**

- 费用公式与 `cost-report.mjs` 一致：cacheHit 0.003 / cacheMiss 0.15 / output 0.6 美元每百万。
- 输出占比 = 输出费用 / 总费用，三档汇总与逐会话求和一致。
- 回收站 meta 里的 `projcacheRow` 与线上 projcache 同构（`agentPreset`、`tokenUsage`、`sessionStats`、`contextBreakdown` 都能取到）。

**误差（写进文档时必须带）**

1. **字符 → token 未校准。** 2.4 的比例是字符比例；回答是中文（约 1.5 字符/token），推理多为英文（约 4 字符/token），所以回答的 token 占比可能高于字符占比，估计 **5–10%**，不是 4%。
2. **日志覆盖不全。** 回收站 109 份 meta，只有 52 份能解析出日志；其余缺日志或解压失败。
3. **子会话未区分。** 线上和回收站都可能把子代理会话当独立行计入，未去重。
4. **历史样本不可比。** 各档任务类型、时长、工具集都不同；只能看构成与趋势，不能做因果。
5. **价格是闲时价。** 峰时三项翻倍，占比不变，绝对金额翻倍。
6. **工具参数含 `edit` 的 old_string**，未拆分；`writeChars` 是字符不是字节。
7. **返工定义宽**：同一路径写 ≥2 次就算，包含正常的迭代修改，是上限不是净值。

**未验证**

- lean v1 / v2 的准确分界：现在按月份切（9 月 = v1，10 月 = v2），需要用预设文件的修改时间核对。
- 桌面版是否认 `DSH_HOME`：阶段 1 第一件事。
- 3 个固定任务的实际费用：预算 $4–6，未跑过。

## 4. 决策记录

| 决策 | 内容 |
|---|---|
| 独立做 | 不并入 dsh-context-budget，不依赖它的插件 |

## 4. 结论分级

**硬的**（可直接写进 README/宣传）

1. 账单三分 44/34/22，每步 $0.0014。
2. 步数是成本主体（每步 = 一次推理 + 一次全文重读）。
3. 删工具 ≈ 0 收益（问答 −26%、文档 +36%、批量 0%、长任务 −13%）。
4. “默认不建文件”在产出文件的任务上贵 36%，且步数 4–14 抖动。
5. 真实浪费是脚手架重写（单文件最多 51 次），不是“模型自发写多余文档”（不要文件的分析任务三次产出字节均为 0）。

- 规则在 200+ 步长会话里的效果：完全没测。
- B3 档案（省掉重新探查）的实际收益：没有实测。

## 6. 坑（都是踩过的，别重犯）

1. **cwd 会进系统提示**：换工作目录 → 前缀缓存整段失效，输入按 0.15 而不是 0.003 计。所以每个 (配置,任务) 固定一个目录。
2. **prompt 缓存只认提示前缀，不认磁盘文件**。保留可复用脚本省的是“重新生成”的推理，不是缓存。
3. **headless 的 one-shot runner 拒绝带 agent preset 的会话**（源码 `assertAdoptable` 直接抛错），且 headless profile 没有 preset 注册插件。所以实验台只能用 profile patch 模拟预设。
4. **精简模式是本地 bundle**：精简模式本地 bundle（`lean-preset` 目录，`@local/dsh-lean-preset`，link 进 `profiles/desktop`），**不在** `~/.dsh/.agent-presets`（那个目录是空的）。它做两件事：删 delegation 组 + persona 加「输出约定」。
5. **隐私**：删文件不等于清理历史，`git rm` 后旧数据仍在旧提交里。正确做法是重建 `.git`。当前仓库已重建，历史单提交，敏感词零命中。
6. **价格口径**：缓存命中 0.003 / 未命中 0.15 / 输出 0.6（美元每百万），闲时。峰时三项翻倍，占比不变。
7. **桌面 vs headless**：桌面真实会话固定税 9.6K/步，headless 只有 5.6K（少 MCP、技能目录、UI 插件）。**比例可迁移，绝对金额不可。**

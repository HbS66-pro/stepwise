# 省 Token 项目：定义与路线

> 状态：v0.1 定义（2026-11-01）
> 本文件取代 `README.md` 中已被推翻的判断（"装配层很少有人系统化输出过"）；README 保留为讨论稿。
> 关联：`精简模式v2-计划.md`、`环境档案.md`、`技能档案1-高频.md`、`技能档案2-归档.md`

## 1. 一句话

**把每轮重发的固定开销和每次新增的输出放进同一套预算，用同一把尺子验收。先做 DSH 适配，再抽成跨 harness 的规格。**

## 2. 定位：我们做哪一段

三条线：输入端（固定税）、输出端（新增量）、度量（验收）。

| 线 | 已被谁覆盖 | 还剩什么 |
|---|---|---|
| 输入端 | 官方 tool search（>85%）、skills 渐进披露；local-ai-dev-harness（两档 preset，1,307 vs 15,567 token/请求）；dsh-context-budget（账本 + G1 工具档） | 三档语义（标准/精简/学习）与切换准则；技能两级档案的离线形态 |
| 输出端 | context-mode（ELv2，98%）、claude-dcp（去重/错误清除）、rtk/ptk（60–90%）、claude-terse（输出 −42~55%） | 交付物"只写结果"的形态规则；载体规则（什么进会话、什么落文件） |
| 度量 | ccusage、cost-report、dsh-context-budget L0 | 同任务净额口径：cache 三分 + 返工次数 |

结论：不做"又一个省 token 框架"，做**改造方法 + 验收标准**；DSH 是第一个适配器，不是产品本体。

## 3. 五个交付物

| # | 交付物 | 管什么 | 生效方式 |
|---|---|---|---|
| 1 | `POLICY.md` | 每轮约束：会话长度、落盘、交付物形态 | 常驻，贴进 AGENTS.md / persona |
| 2 | `SETUP.md` | 一次性结构改造：三档、技能档案、度量安装 | AI 照做，带验收与回滚 |
| 3 | `adapters/dsh/presets/{standard,lean,study}` | 工具 / 技能 / persona 装配 | 建会话时 |
| 4 | `tools/output-report.mjs` | 三个数：每步输出、落盘字节、返工次数 | 只读，随时跑 |
| 5 | `skills/{deliver-doc,make-ppt}` | 一类任务怎么做 | 按需加载 |

插件放第二期：只有规则执行率不达标，才做强制（账本 / 守卫）。

## 4. 固定税清单

算：AGENTS.md、系统提示、工具表、常驻技能目录（name + description）、persona。
不算：环境档案、两级技能档案、交付物文件——它们只在被读时进入上下文，属于工具结果侧。

## 5. 输出端规则（草案）

1. 会话只放结论，默认 ≤15 行
2. 超过 8 KB 或 200 行的内容落文件，会话只回路径 + 3 行摘要
3. 交付物只写结果：删背景铺垫、思考过程、自查记录、"下一步建议"、客套
4. 工作稿与交付物分目录，工作稿可丢
5. 同一文件不在会话里写第二遍；返工要说明原因

任务预算（起始值，基线后调）：

| 任务 | 会话回答 | 文件 |
|---|---|---|
| 问答 | ≤10 行 | 不落盘 |
| 调研 / 分析 | ≤20 行（可带表） | 需要留档才写 |
| 文档 | ≤5 行 + 路径 | 只结果 |
| PPT | ≤5 行 + 路径 | 先大纲后生成 |

## 6. 度量设计

三个数：

1. 每步 output token（会话 usage 的 `outputTokens`）
2. 落盘字节（每次 write/edit 累计）
3. 返工次数（同一路径在会话内被写 ≥2 次）

两层：

- **描述层**：历史会话，按档、按任务归一，回答"钱花在哪"
- **对照层**：三级阶梯，固定 3 个任务，独立 `DSH_HOME` 跑，不碰日常配置

对照阶梯（每次只加一层）：

| 配置 | 内容 | 回答什么 |
|---|---|---|
| C0 | DSH 默认（空 AGENTS、默认 preset、默认技能） | 读者装包前的起点 |
| C1 | C0 + 输入端改造（三档、技能档案、AGENTS 索引） | 输入侧贡献多少 |
| C2 | C1 + 输出端改造（POLICY、落盘规则） | 输出侧贡献多少 |

旧版 lean 不参与对照：它是日常车，混了多轮改造，不能当坐标；只用来查"新版有没有退步"。别人的仓库数字只当量级参考，除非把他们的包装进同一实验台跑同一批任务。

口径：cacheRead / uncachedInput / output 三分开报；价格用闲时与峰时两档；标注实测还是估算；子会话单独计。

## 7. 已有数据（2026-11-01，35 个会话）

| 档 | 会话 | 输出 token | 输出占账单 |
|---|---|---|---|
| lean（旧版精简） | 30 | 6.02M | 48% |
| standard | 3 | 0.23M | 21% |
| study | 2 | 0.69M | 42% |

全部合计：输出 6.93M、缓存读 1.096B、未缓存输入 11.66M；按 deepseek-flash 闲时价约 $9.2，其中输出 45%、缓存读 36%、未缓存输入 19%。

说明：输出只占 token 总量 0.6%，却占账单 45%。standard 只有 3 个会话且明显更短，**不可比**；以上是描述性数字，不能当因果结论。

## 8. 路线

| 步 | 做什么 | 产出 | 动配置 |
|---|---|---|---|
| 1 | 写 `output-report.mjs`，读历史会话 | 三分占比 + 分档表 | 只读 |
| 2 | 补落盘字节、返工次数 | 三个数齐 | 只读 |
| 3 | 固定 3 任务跑基线（问答/文档/PPT） | before 表 | 只读 |
| 4 | 写 POLICY 贴进 AGENTS.md，重跑 | 第一个净额 | 改（可回滚） |
| 5 | 三档 preset + SETUP.md | 可交付包 | 改 |
| 6 | 抽通用层，DSH 降为第一个 adapter | 契约 | — |

## 9. 硬约束

- DSH hook 桥只支持 5 个事件（SessionStart / UserPromptSubmit / PreToolUse / PostToolUse / Stop），没有 PreCompact / PostCompact；不支持改写工具输出
- hook 配置进程级、启动读一次，不随档切换
- 三档只能切工具 / 技能 / persona；输出侧 hook 全局一份
- 用户预设目录是 `~/.dsh/.agent-presets/<id>/preset.yml`（源码 `USER_PRESET_DIR` / `METADATA_FILE`）
- 换 preset 可能让旧会话作废，必须写进 README 第一屏

## 10. 不做

有损压缩（LLMLingua 式）、模型路由、语义索引代码库、调 compaction 阈值、v0.1 上插件、做框架或插件市场。

## 11. 风险

- 历史样本不可比：只做方向，不做因果
- 改造书会改用户机器：必须备份、幂等、验收、可回滚
- 第三方代码协议：MIT 可用并署名；ELv2 / AGPL 只读思路
- 窗口在关：DSH 上已有两个同构项目（10-12 的 local-ai-dev-harness、10-22 的 dsh-context-budget）
